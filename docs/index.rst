LungViZ User Guide
==================

LungViZ is an interactive viewer for one-dimensional OpenCMISS and CMGUI
meshes, point data, triangulated surfaces, and CT volumes. Use it to inspect
airway or vessel branches, visualise fields such as flow and radius, and
compare geometry with grayscale CT slices in the same 3D scene.
